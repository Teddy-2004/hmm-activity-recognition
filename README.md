# Human Activity Recognition with a Hidden Markov Model

ALU Formative 2 (individual), Tedla Tesfaye Godebo.

A Gaussian HMM, implemented from scratch in numpy (forward–backward, Baum–Welch with a log-likelihood
convergence check, Viterbi), that infers *still / standing / walking / jumping* from smartphone
accelerometer and gyroscope data recorded with Sensor Logger (iPhone 13 Pro Max, 100 Hz).

## Contents
| Path | What |
|---|---|
| `hmm_activity_recognition.ipynb` | full pipeline: loading, resampling, windowing, features, HMM, evaluation, figures |
| `data/train/` | 52 labelled recordings (13 per activity), one CSV each |
| `data/raw/` | original Sensor Logger exports |
| `data/test/` | 2 unseen test recordings with segment labels |
| `figures/` | every figure used in the report (generated by the notebook) |
| `HMM_Activity_Recognition_Report.pdf` | the 5-page report |

## Results
- Unseen test data (2 continuous recordings, 91 windows): **91.2 % accuracy**; all errors fall at activity switches.
- Cross-session validation (train on one recording session, test on the other): 100 % (369 windows).
